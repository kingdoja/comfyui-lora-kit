# 任务 3：资产库

## 目标

资产库为训练和生图提供统一素材入口，支持车型、模型、图片素材、LoRA 产物和生成结果的管理。

设计图中资产分类包含：

- 车型
- 实车类
- 产品类
- 汽车类
- 模型

建议整理成可扩展分类，而不是只写死几类。

## 分类建议

一级分类：

- `vehicle`：车型。
- `real_vehicle`：实车类。
- `product`：产品类。
- `automotive`：汽车类。
- `model`：模型资产。

二级分类可按业务继续扩展：

- 车型：ATV、UTV、scooter、e-bike、robot mower。
- 视角：front、side、rear、top、three_quarter。
- 场景：studio、outdoor、road、desert、city、garage。
- 用途：training、reference、controlnet_input、generated_result。
- 模型：checkpoint、lora、controlnet、vae。

## 资产库节点建议

### Ninebot Asset Selector

输入：

- `category`
- `subtype`
- `tags`
- `quality_min`
- `limit`

输出：

- `image`
- `image_path`
- `caption`
- `asset_meta`

### Ninebot Asset Register

输入：

- `image` 或 `file_path`
- `category`
- `tags`
- `caption`
- `quality_score`
- `source`

输出：

- `asset_id`
- `asset_meta`

### Ninebot Model Asset Selector

输入：

- `model_type`：checkpoint、lora、controlnet、vae。
- `task`：training、generation、control。
- `tags`

输出：

- `model_path`
- `model_meta`

```json
    "caption": "captions/asset_20260623_000001.txt"
  },
  "created_at": "2026-06-23T19:00:00+08:00",
  "updated_at": "2026-06-23T19:00:00+08:00"
}
```

## 打标与评分

资产库里的“打标”包含三种不同信息：

- `tags`：检索和筛选用。
- `caption`：训练和生图 prompt 用。
- `quality_score`：可选评分，用于过滤训练素材。

因此“打标是评分吗？”的答案是：不是。评分只是打标体系里的一个可选字段。

## 上传流程

1. 上传图片或模型文件。
2. 生成缩略图和基础信息。
3. 自动建议 tags 和 caption。
4. 人工复核。
5. 保存元数据。
6. 可加入训练集或生图参考集。

## 与另外两个任务的接口

给 LoRA 训练：

- 输出 `dataset_id`。
- 提供图片路径列表。
- 提供 caption sidecar。
- 支持按 `quality_score`、分类、标签筛选。

给 LoRA 生图：

- 输出参考图。
- 输出提示词片段。
- 输出模型路径。
- 保存生成结果和参数。

## 验收标准

- 可以上传图片并生成缩略图。
- 可以填写/修改分类、标签、caption、评分。
- 可以按分类和标签检索。
- 可以把一组资产保存成训练集。
- 可以选择 LoRA/checkpoint/ControlNet 类型的模型资产。
- 所有数据保存在独立新目录，不写入既有业务文件。
